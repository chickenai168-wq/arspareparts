# AR Spare Parts

Production website repository for **AR Spare Parts** (`arspareparts.com`).

## Stack

- Next.js (App Router)
- TypeScript
- Static product data (JSON) for the initial production release
- Vercel deployment

## Repository structure

- `src/app/` — application routes
- `src/components/` — shared UI components
- `src/lib/` — product/data utilities
- `src/types/` — TypeScript types
- `content/products/` — product data
- `public/images/` — owned website assets
- `scripts/` — import and validation scripts
- `docs/` — release/maintenance documentation

## Workflow

Changes should be kept in small, reviewable commits. Preview deployments are checked before production release.

## Domain

Production domain: `arspareparts.com`
